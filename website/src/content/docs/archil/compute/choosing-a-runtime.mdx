Archil runs your code four ways:

- **Services** run your own program in a sandbox, at a public URL. Use
  them for APIs and websites.
- **Sandboxes created at run time** run commands per task, such as an
  agent's tool calls, each in its own microVM.
- **Serverless exec** runs one command against a disk and shuts down.
- **Mounts** attach a disk to a host you already run: a Cloudflare
  Container or an ECS task.

| | Service | Run-time sandbox | Serverless exec | Mount |
| --- | --- | --- | --- | --- |
| Resource or binding | `Archil.Service` | `Archil.CreateSandbox` | `Archil.ExecDisk` | `Archil.MountDisk` |
| Runs | your bundled program | commands you send | one shell command | your host's program |
| Lifetime | until destroyed; stops when idle, wakes on request | until you delete it | one call, up to 5 minutes | the request's scope |
| Reached by | public `https://` URL | your code, over the process API | the call's result | the host's own filesystem |
| Cost when idle | none while stopped | none while paused | none | your host's |

## Services

Declare a sandbox and a service in it. See [Services](/archil/compute/services).

```typescript
// src/api.ts
import * as Archil from "@alchemy.run/archil";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";

export const Box = Archil.Sandbox("Box", {});

export default class Api extends Archil.Service<Api>()(
  "Api",
  { sandbox: Box, main: import.meta.url },
  Effect.gen(function* () {
    return { fetch: Effect.succeed(HttpServerResponse.text("hello")) };
  }),
) {}
```

## Run-time sandboxes

Bind an image and create a sandbox per task. See
[Sandboxes](/archil/compute/sandboxes).

```typescript
const sandboxes = yield* Archil.CreateSandbox(Agent);
const sandbox = yield* sandboxes.create({ name: `task-${id}` });
const result = yield* sandbox.exec("npm test");
```

## Serverless exec

Run a command with a disk mounted, and pay only for the call. See
[Disks](/archil/storage/disks).

```typescript
const dataset = yield* Archil.ExecDisk(Dataset);
const result = yield* dataset.exec("wc -l /mnt/archil/*.csv");
```

## Mounts

Mount a disk inside your own container per request. See
[Mounting](/archil/storage/mounting).

```typescript
const dataset = yield* Archil.MountDisk(Dataset, { readOnly: true });
const path = yield* dataset.mount({ mode: "read-only" });
```
