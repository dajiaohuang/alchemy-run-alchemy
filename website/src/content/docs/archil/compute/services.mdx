An [`Archil.Service`](/providers/archil/reference/service) is your program running
in an [`Archil.Sandbox`](/archil/compute/sandboxes). Alchemy bundles it,
uploads it, and registers it with the sandbox's service manager, which
restarts it if it crashes and starts it whenever the sandbox boots. Its
port gets a public `https://` URL.

## Declare a sandbox

Services run in a sandbox you declare. Several services can share one:

```typescript
// src/box.ts
import * as Archil from "@alchemy.run/archil";

export const Box = Archil.Sandbox("Box", {});
```

## Write an Effect service

The class form takes the sandbox, `main: import.meta.url`, and the port.
The Effect returns the handlers:

```typescript
// src/api.ts
import * as Archil from "@alchemy.run/archil";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Box } from "./box.ts";

export default class Api extends Archil.Service<Api>()(
  "Api",
  { sandbox: Box, main: import.meta.url, port: 3000 },
  Effect.gen(function* () {
    return {
      fetch: Effect.succeed(HttpServerResponse.text("hello")),
    };
  }),
) {}
```

## Deploy it

Yield the service from your Stack and return its URL:

```typescript
// alchemy.run.ts
import * as Archil from "@alchemy.run/archil";
import * as Alchemy from "alchemy";
import * as Effect from "effect/Effect";
import Api from "./src/api.ts";

export default Alchemy.Stack(
  "MyApi",
  { providers: Archil.providers(), state: Alchemy.localState() },
  Effect.gen(function* () {
    const api = yield* Api;
    return { url: api.url };
  }),
);
```

Run `alchemy deploy`. `url` is `https://3000-<id>.<region>.archil.app`.

## Bind a disk

Bindings resolve when the service starts. `Archil.ReadDisk` gives the
service a read-only S3 user on one disk:

```diff lang="typescript"
// src/api.ts
export default class Api extends Archil.Service<Api>()(
  "Api",
  { sandbox: Box, main: import.meta.url, port: 3000 },
  Effect.gen(function* () {
+    const files = yield* Archil.ReadDisk(Dataset);
    return {
-      fetch: Effect.succeed(HttpServerResponse.text("hello")),
+      fetch: Effect.map(files.getText("README.md"), (text) => HttpServerResponse.text(text)),
    };
-  }),
+  }).pipe(Effect.provide(Archil.ReadDiskHttp)),
) {}
```

## Write an async service

Point `main` at a plain module whose default export has
`fetch(request, env)`. Alchemy bundles it with no Effect runtime:

```typescript
// alchemy.run.ts
import * as Archil from "@alchemy.run/archil";
import { Box } from "./src/box.ts";

export const Hello = Archil.Service("Hello", {
  sandbox: Box,
  main: "./src/hello.ts",
  port: 3001,
  env: { GREETING: "hello" },
});

export type HelloEnv = Archil.InferEnv<typeof Hello>;
```

## Type its environment

`Archil.InferEnv` turns the service's `env` into the handler's `env`
argument:

```typescript
// src/hello.ts
import type { HelloEnv } from "../alchemy.run.ts";

export default {
  async fetch(request: Request, env: HelloEnv) {
    return new Response(`${env.GREETING} from ${new URL(request.url).pathname}`);
  },
};
```

## Install native packages

Packages in `build.install` are installed next to the program with
`npm install` instead of bundled:

```typescript
// alchemy.run.ts
export const Hello = Archil.Service("Hello", {
  sandbox: Box,
  main: "./src/hello.ts",
  build: { install: ["sharp"] },
});
```

## Idle sandboxes

A sandbox stops after its idle timeout, and the next request to a
service's URL starts it again, usually in a few seconds. Set
`idleTtlSeconds: 0` on the sandbox to keep it running.
