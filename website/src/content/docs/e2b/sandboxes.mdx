---
title: Sandboxes
description: Create sandboxes from a Worker, run commands, read and write files, and manage their lifecycle.
---

You create sandboxes at runtime with `E2B.CreateSandbox`. Pass a template or snapshot to create from it, or nothing and pass `templateID` per call.

```typescript
// in the Worker's construction
const sandboxes = yield* E2B.CreateSandbox(Agent);
```

Provide `E2B.CreateSandboxHttp` on the Worker. The Worker gets its own E2B API key as a secret, revoked when the Worker is destroyed.

## One sandbox per request

```typescript
// in fetch
const sandbox = yield* Effect.acquireRelease(sandboxes.create({ timeout: 120 }), (sandbox) =>
  Effect.ignore(sandbox.kill()),
);
```

The sandbox is killed when the request's scope closes. `timeout` is in seconds; E2B kills the sandbox when it runs out.

## A long-lived sandbox per user

```typescript
const [existing] = yield* sandboxes.list({ metadata: { user }, state: ["running", "paused"] });
const sandbox = existing
  ? yield* sandboxes.connect(existing.sandboxID, { timeout: 600 })
  : yield* sandboxes.create({ metadata: { user }, autoPause: true, timeout: 600 });
```

With `autoPause`, E2B pauses the sandbox instead of killing it when the timeout runs out, memory included. `connect` resumes it.

## Run commands

```typescript
const result = yield* sandbox.commands.run("npm test", { cwd: "/home/user/app" });
// { stdout, stderr, exitCode, pid, error }
```

A non-zero exit code is returned, not failed. `commands.exec(["node", "--version"])` runs an argument vector without a shell.

## Stream output

```typescript
const events = sandbox.commands.start("npm run build");
// a Stream of Start, Stdout, Stderr, then End with the exit code
```

Interrupting the stream detaches; the process keeps running. Re-attach with `commands.connect({ pid })` or stop it with `commands.kill({ pid })`.

## Files

```typescript
yield* sandbox.files.write("/home/user/app/config.json", JSON.stringify(config));
const log = yield* sandbox.files.readText("/home/user/app/out.log");
const entries = yield* sandbox.files.list("/home/user/app");
```

`files.watch(path)` streams changes under a directory.

## Pseudo-terminals

```typescript
const pty = sandbox.pty.create({ cols: 120, rows: 40 });
yield* sandbox.pty.sendInput({ pid }, "ls\n");
```

## Ports

```typescript
const res = yield* sandbox.fetch(3000, HttpClientRequest.get("/health"));
const url = sandbox.url(3000); // https://3000-<sandboxId>.e2b.app
```

## Lifecycle

```typescript
yield* sandbox.setTimeout("30 minutes");
yield* sandbox.pause();
yield* sandbox.kill();
```

## Clean up on destroy

Every sandbox a Worker creates carries its stage and the Worker in its metadata. When you destroy the Worker, the sandboxes it left running or paused are killed. To keep them, bind with `E2B.CreateSandbox(Agent, { onDestroy: "retain" })`.
