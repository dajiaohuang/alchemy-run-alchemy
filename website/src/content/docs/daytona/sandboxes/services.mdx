---
title: Services
description: Run an Effect program in a sandbox and serve it on the sandbox's preview URL.
---

A `Daytona.Service` is an Effect program that runs inside a sandbox. Alchemy bundles it, uploads it, and runs it with Node; requests reach it through the sandbox's preview URL.

## Declare the sandbox it runs in

```typescript
// src/Box.ts
import * as Daytona from "@alchemy.run/daytona";

export const Box = Daytona.Sandbox("Box", { public: true, autoStopInterval: 0 });
```

`public` opens the preview URL to anyone. `autoStopInterval: 0` keeps the sandbox, and so the program, running.

## Serve a program from it

```typescript
// src/Api.ts
import * as Daytona from "@alchemy.run/daytona";
import * as Effect from "effect/Effect";
import * as HttpServerResponse from "effect/http/HttpServerResponse";
import { Box } from "./Box.ts";

export default class Api extends Daytona.Service<Api>()(
  "Api",
  { sandbox: Box, main: import.meta.url, port: 3000 },
  Effect.gen(function* () {
    return {
      fetch: Effect.succeed(HttpServerResponse.json({ ok: true })),
    };
  }),
) {}
```

`api.url` is the preview URL of port 3000. Several Services can share one sandbox on different ports.

## Redeploy

A change to the program uploads the new bundle and restarts the process. The sandbox and the URL stay the same.

If the sandbox stopped, its process ended with it. The next deploy starts the sandbox and the program again.

## Use bindings

```typescript
Effect.gen(function* () {
  const box = yield* Daytona.ConnectSandbox(Box);
  return {
    fetch: Effect.gen(function* () {
      const self = yield* box.getSandbox();
      return yield* HttpServerResponse.json({ state: self.state });
    }),
  };
}).pipe(Effect.provide(Daytona.ConnectSandboxHttp));
```

The program reaches the internet the way its sandbox does. Below Daytona's Tier 3, sandboxes reach only an allowlist of essential services (package registries, GitHub, AI APIs, Daytona's API), so bindings that manage sandboxes work but toolbox calls are refused. From Tier 3, sandboxes have full internet access.

## Keep it private

Leave the sandbox private and callers send its preview token:

```typescript
const { token } = yield* sandboxes.getPortPreviewUrl({ sandboxIdOrName: api.sandboxId, port: 3000 });
const res = yield* client.get(api.url, { headers: { "X-Daytona-Preview-Token": token } });
```
